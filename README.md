# packages

Public mirrors of installer packages, published as GitHub Release assets.

## Cloudflare WARP (macOS)

The [Publish Cloudflare WARP](.github/workflows/warp.yml) workflow downloads the
WARP `.pkg` from Cloudflare and attaches it to a `warp-<version>` release.
Run it from the Actions tab with a version number, or edit the default in the workflow.

Download: https://github.com/turnhub/packages/releases/download/warp-2026.8.2115.0/Cloudflare_WARP_2026.8.2115.0.pkg
